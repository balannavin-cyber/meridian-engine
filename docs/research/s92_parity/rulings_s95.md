This is the single source for the S95 rulings. Other documents point here and do not restate
the rulings. It sits beside `rulings_s92.md` … `rulings_s94.md` in this directory.

| # | Ruled | Topic | Ruling | Basis |

| **S95-A** | 2026-10-11 | Rule 23 on non-trading days | **Rule 23's 08:30–15:40 IST window binds trading days only.** On a weekend or holiday the fixture suite may run at any hour. **The `ulimit -v` clause always applies.** | The window exists so the suite cannot contend with the live capture chain (TD-S91-NEW-7, OOM at 08:51 and 08:58 IST on a trading day). With markets shut there is no capture chain to protect. The memory bound protects the box regardless of the clock. |
| **S95-B** | 2026-10-11 | P5 (PPC-1): what "previous close" is | **The baseline is the session's PRE-OPEN row**: the first snapshot of the session date in the front expiry, **refused if stamped at or after 09:15 IST** (absence, never a fallback). **A view**, not a table. **Front expiry only.** After the drill: **no anchor guard.** Built as `v_oi_since_preopen` (`21d3142`, Section 4 `47989ed`), LIVE 2026-10-11. | Measured S95 over 26 changeovers per symbol (`docs/research/s95_priority/p5/P5_preopen_baseline_note_2026-10-11.md`): on NIFTY the pre-open row **is** the 15:40 close on every leg (26/26); on SENSEX it differs on 23–41 % of legs nightly (BSE revises OI overnight), so anchoring there keeps the revision out of the day's flow. It reads only the session's own rows, so the missing 10-02 calendar row cannot reach it. Anchor seek 0.18 ms. The SENSEX outliers (48.8 M) are vendor OI on untraded legs, constant through whole sessions, which a guard on one row cannot catch. |
| **S95-C** | 2026-10-11 | ADR-015's sign-convention gloss (P6 carry 7) | **Amend ADR-015 to correct the English only.** The amendment quotes ADR-014 §2.3 (*calls dealer-long, puts dealer-short* as the reading of the `+CE −PE` term) in place of the inverted gloss (*"dealers short calls and long puts"*), and states that the sign is **open-interest arithmetic, not a dealer claim** (P2: dealer side regime-dependent). **No code, view or board change.** | P6 design note §3.1: the code is not in doubt (`signed_gamma_exposure` negates PE only; reconstruction to 1.17e-9 Cr). The ADR's sentence is the exact inverse of the text it claims to carry unchanged. A wrong sentence in an ACCEPTED ADR is corrected by amendment, not left for a reader to find. |
| **S95-D** | 2026-10-11 | Does a BUILT layer that later breaks reopen parity? (left open by ADR-025 Amendment D) | **No. A break is maintenance**: fixed under the Change Protocol, the layer stays BUILT. **Parity reopens for a layer only if it is removed or its definition changes**, and either needs an ADR-025 amendment. | ADR-025 D2 dispositions are about what was built against the spec; a defect in a built layer is ordinary maintenance (CLAUDE.md settled decision on Amendment D). Reopening on every break would make the disposition a health status, which ADR-031's contracts already carry. |
