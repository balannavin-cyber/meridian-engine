## How the diff runs

| Check | v0 (now) | When it becomes a deploy gate |
|---|---|---|
| **Replay determinism** | Re-run `ladder_replay_1001.sql` against the live DB and diff with the S89 CSV. Identical ⇒ the stored day has not changed and the SQL is deterministic | Now, as a one-off; the freeze script prints the result |
| **Replay against frozen inputs** | Load `inputs/` into a scratch schema, point the replay SQL at it, diff with `expected/` | R2.1 SC step: needs a scratch schema (DDL) |
| **Engine recompute** | Run the engine's compute on `inputs/ocs` and diff with frozen `gex_strike` / `gamma_metrics` | After **R2.6** (purity, `as_of`): today the compute reads latest-only views and the wall clock, so it cannot be pointed at a past day |
| **Ladder vs reference** | Leader, top-5 set and % of leader per cycle vs `ref_…` §7 | With R2.3 (independent recompute) |

Tolerances: exact for counts, keys, strikes, leader and top-5 sets; numeric fields to 1e-9 relative unless a field's definition says otherwise. Any difference is reported per field, never collapsed to pass/fail.

## Run

Paste `s90_golden_1001_freeze.sh` on the box after the close. Read-only on the database (`bin/roq.sh`); writes only under the fixture directory. It prints per-file row counts and sizes, the counts table, and **REPLAY DETERMINISTIC** or the first 20 diff lines.
